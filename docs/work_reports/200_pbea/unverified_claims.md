# Unverified and prohibited claims

The following statements are not supported by this experiment and must not appear as conclusions:

- PBEA stops all malware, insiders, supply-chain attacks, or zero-days.
- PBEA is a complete Zero Trust Architecture or replaces authentication/authorization.
- pledge/unveil enforces destination-specific network policy.
- B0 or B1 is intentionally vulnerable software representative of all access-control systems.
- 0 observed successes proves a true attack-success probability of zero.
- The measured mixed-scenario latency is production throughput or steady-state request latency.
- The result generalizes to Linux, Windows, other BSD versions, distributed quarantine, or arbitrary domains without further evidence.

No additional paper claim remains verified beyond the bounded entries in `claim_evidence_matrix.md`.
